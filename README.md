# Mesto — работа с сервером

Адаптивная страница для обмена фотографиями. Проект создан на JavaScript и Vite по заданию «Mesto. Работа с сервером», заключительное задание — вариант 1.

**Опубликованный проект:** [Mesto на GitHub Pages](https://orlovviktor-idb-24-02.github.io/mesto-pages/).

**Исходники:** [OrlovViktor-idb-24-02/mesto](https://github.com/OrlovViktor-idb-24-02/mesto).

## Возможности

- Профиль и карточки загружаются с API через `Promise.all`.
- Редактирование имени, описания и аватара.
- Создание карточек и подтверждение удаления собственных карточек.
- Постановка и снятие лайков, счётчик из ответа сервера.
- Просмотр фотографии в модальном окне.
- Статистика карточки: название, автор, дата создания, количество лайков и пользователи, поставившие лайк. Перед открытием данные повторно запрашиваются с сервера. Разметка статистики создаётся клонированием HTML-шаблонов.
- Проверка полей форм, блокировка повторной отправки, сообщения об ошибках и тексты состояния загрузки.
- Закрытие модальных окон по Escape, кнопке и фону; удержание фокуса в диалоге.
- Адаптация под мобильный экран от 320 px. Шрифт Inter хранится локально в сборке.

## Запуск

Требуется Node.js 22.12 или новее. Рекомендуется Node.js 24.

```sh
npm ci
npm run dev
```

При новом клонировании скопируйте `.env.example` в `.env` и заполните значения:

```dotenv
VITE_MESTO_TOKEN=ваш_токен_Mesto
VITE_MESTO_COHORT=ваша_группа
```

Не добавляйте `.env` в Git: файл исключён через `.gitignore`. Переменные `VITE_*` встраиваются в клиентскую сборку и видны в браузере. Это учебный токен Mesto; токен GitHub в приложение добавлять нельзя.

Публичная версия собирается отдельной командой `npm run build:public`: она исключает токен из файлов. На опубликованной странице нажмите «Подключить Mesto» и введите группу и токен. Они хранятся в `sessionStorage` текущей вкладки и отправляются только учебному API при запросах.

## Сборка и проверка

```sh
npm run check
npm run build
npm run preview
```

Готовая сборка находится в `dist/`. Настройка `base: './'` позволяет разместить её в подпапке GitHub Pages.

## Публикация на GitHub Pages

Автоматическая публикация настраивается в репозитории `mesto`: **Settings → Pages → Source → GitHub Actions**. Workflow проверяет код, собирает публичную версию без токена и публикует артефакт при каждом push в `main`. Он использует встроенный краткосрочный `GITHUB_TOKEN`; отдельный Personal Access Token не нужен. Адрес этой публикации: `https://orlovviktor-idb-24-02.github.io/mesto/`.

Отдельный репозиторий `mesto-pages` содержит только готовую сборку. Его можно обновить локальной командой:

```sh
npm run deploy
```

Команда `npm run deploy` собирает публичную версию и отправляет содержимое `dist/` в ветку `main` репозитория `mesto-pages` через библиотеку `gh-pages`. Для неё Git на компьютере должен быть авторизован в аккаунте владельца репозитория. В `mesto-pages` выбрано **Settings → Pages → Deploy from a branch → main → / (root)**.

Автоматический workflow также можно запустить вручную через **Actions → Deploy Mesto to GitHub Pages → Run workflow**.
